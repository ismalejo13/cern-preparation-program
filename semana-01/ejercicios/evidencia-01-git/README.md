# Evidencia 1 — Primer repositorio con Git

En este ejercicio practiqué los comandos básicos de Git siguiendo la guía de Software Carpentry.

## Qué aprendí
Aprendí a crear un repositorio local, guardar cambios con commits y revisar el historial de lo que voy modificando.

## Dificultad encontrada
Al principio me costó entender la diferencia entre git add y git commit, porque parecía que hacían lo mismo, hasta que entendí que add prepara los cambios y commit los guarda de verdad.
