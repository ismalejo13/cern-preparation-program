# CERN Preparation Program

## Sobre este repositorio
Este repositorio documenta mi participación en el CERN Preparation Program, semana a semana, con las actividades y evidencias que voy entregando.

## Objetivo personal
Quiero aprovechar este programa para entender cómo se maneja y analiza información real de experimentos científicos, usando herramientas de programación que ya conozco pero aplicadas a un contexto que nunca había visto, como los datos abiertos del CERN.

## Áreas que quiero fortalecer
- Manejo de datasets grandes y formatos poco comunes como ROOT
- Uso de Python para análisis de datos con librerías como uproot y awkward
- Documentación y organización de proyectos técnicos
- Trabajo con control de versiones en Git y GitHub
